## 一、指标定义

| 字段 | 值 |
|------|-----|
| 指标名称 | 应市项目按计划实施率 |
| 业务含义 | 统计当月应市类项目中正常执行+按期结题的比例，反映项目计划执行的健康度 |
| 计算公式 | (正常项目数 + 结题项目数) / (正常项目数 + 延期项目数 + 暂停项目数 + 结题项目数) × 100% |
| 管理口径 | 项目维度（按项目个数计数） |
| 时间粒度 | 月度（当月快照） |
| 覆盖范围 | PS/PA/PB/PC1/PC2/HW/FH类应市项目，仅终端+光模块事业部 |
| 维度 | 事业部×产品线、项目经理 |

## 二、核心业务规则

### 项目情况判定（5种互斥，优先级从高到低）

| 状态 | 判定规则 | 纳入合计分母 |
|------|----------|-------------|
| 结题 | 鉴定实际完成时间在当月 | ✅ |
| 延期 | 非结题，开发/鉴定实际完成 > 计划+3工作日 | ✅ |
| 暂停 | projectcurrent = 'Hold' | ✅ |
| 终止 | projectcurrent = 'Cancel'，当月有取消单且无恢复单 | ❌ |
| 正常 | 不属于以上任何一种 | ✅ |

### +3工作日计算

基于 `ods.odsrdm_holiday` 表（仅存储工作日）：
1. 找到计划完成时间对应的最近工作日id
2. id+3 对应的 date_time 即为截止日
3. 实际完成 > 截止日 → 延期
