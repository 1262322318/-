## 业务背景
集团需要按月监控各事业部的在产型号数量。在产型号数反映当前正在生产的产品型号规模，是衡量产品研发投入和生产复杂度的核心指标。与在销型号数不同，在产型号数关注的是生产端的型号管理。

### 核心逻辑
- **在产型号判定**：从在销型号明细表中筛选 `model_label_10 = '在产'` 的型号
- **冰冷洗**：在在销型号基础上，额外剔除非海信自有工厂代工产品（只保留海信自有工厂生产的型号）
- **空调**：直接继承在销型号的在产判定逻辑
- **视像科技**：直接继承在销型号的在产判定逻辑
- **ADS层汇总**：按公司/产品线/内外销维度聚合在产型号数，支持产品型号口径和生产版本口径两种统计方式

## 涉及数据表

### 源表（读取）
- `dws.dws_ipd_ipm_sale_model_detail_dd` — 在销型号明细表（筛选在产型号）
- `dws.dws_ipd_ipm_zcmodel_detail_dd` — 在产型号明细表（ADS层读取）
- `dws.dws_ipd_ipm_zcproductionversion_dd` — 在产生产版本明细表（生产版本口径）

### 目标表（写入）
- `dws.dws_ipd_ipm_zcmodel_detail_dd` — 在产型号明细表（DWS层）
- `ads.ads_ipd_ipm_zcmodel_result_dd` — 在产型号数结果表（ADS层）

## 数据流程
```
dws.dws_ipd_ipm_sale_model_detail_dd (在销型号明细，筛选在产)
         ↓
dws.dws_ipd_ipm_zcmodel_detail_dd (在产型号明细：剔除代工产品)
         ↓
ads.ads_ipd_ipm_zcmodel_result_dd (在产型号数结果：按公司/产品线/内外销汇总)
```

## 关键指标
- `model` — 产品型号名称
- `is_project` — 是否保护期（Y=不纳入统计，N=纳入统计）
- `act_num` — 在产型号数（ADS层汇总值）
- `data_type` — 数据类型（在产型号-产品型号口径 / 在产型号-生产版本口径）

## 业务规则

### 本指标专属规则
- **在产型号判定**：从在销型号明细中筛选 `model_label_10 = '在产'` 的型号
- **冰箱内销代工剔除**：只保留海信自有工厂（扬州/平度/成都/顺德）生产的型号
- **冰箱外销代工剔除**：剔除指定代工工厂（奥马/双鹿/VESTEL/韩电等）
- **冷柜代工剔除**：剔除指定代工工厂（万宝/创维/双鹿/星星）
- **洗衣机代工剔除**：只保留平度洗衣机工厂生产的型号
- **双口径统计**：支持产品型号口径和生产版本口径两种统计方式

### 引用公共规则（详见 .kiro/steering/business_rules.md）
- **PUB-001**：保护期规则（继承在销型号的保护期判定）
- **PUB-003**：产品线分类规则-冰冷洗
- **PUB-006**：空调产品线分类规则
