## 一、需求概述

### 业务背景
每月手动从 PLM 导出全项目状态原始报表，人工筛选当月实际完成项目并逐个查开始/完成日期、计算开发周期，繁琐、耗时、易错（月均 4.5H 工时）。需求转为自动化报表：从 PLM 自动获取项目原始数据与产品线维度，自动识别完成状态、计算开发周期、生成并导出报表。

### 业务目标
- 月节省 ≥4H 人工工时
- 准确率提升至 100%
- 报表落在"信数 → 研发管理"版块

## 二、指标定义

### M1 应市项目平均开发周期（核心 · 确定 · 已落地）

| 项 | 值 |
|----|-----|
| 计算公式 | 范围内各项目（完成时间−立项时间−暂停总天数）取平均 |
| 统计粒度 | 按"项目"统计（非按产品型号） |
| 时间口径 | 完成时间落在当月的项目纳入当月统计 |
| 周期单位 | 自然日 |
| 小数位 | 默认保留 1 位小数【默认待确认·遗留-2】 |
| 维度 | 产品线（终端/光模块）× 月 |
| 产品线维度 | 终端={BOX, Multimedia}；光模块={A1, A2, A3, A4, Coherent} |

### M2 完成率（衍生 · 低确定度·待定）

| 项 | 值 |
|----|-----|
| 计算公式 | `2 − 实际值 / 目标值` |
| 依赖 | 目标值模拟表（结构未定，遗留-1） |
| 状态 | **BLOCKED**：目标值表结构闭环前不得落地 |

### M3 同比改善（衍生 · 中确定度）

| 项 | 值 |
|----|-----|
| 计算公式 | `1 − 实际值 / 同期值` |
| 同期值 | 去年同月 M1 实际值（同口径回算） |
| 状态 | 待确认去年同月无数据时取值策略（Q2） |

## 三、公共规则

| 编号 | 规则 | 精确口径 |
|------|------|----------|
| R1 | 项目范围：仅"应市类" | `HBMTPDERIVETYPE` ∈ {所有PA*, 所有PB*, PC1, PC2} |
| R2 | 统计粒度 | 按项目统计 |
| R3 | 时间口径 | `HBMTPPRODUCTIONACTUALEDATE` 所在自然月 |
| R4 | 周期单位 | 自然日 |
| R5 | 暂停剔除 | 开发周期 = (完成−立项) − Σ(恢复−暂停)，时间取 RELEASEDATE |
| R6 | 内外销 | 不区分 |
| R7 | 产品线维度 | 终端={BOX,Multimedia}；光模块={A1,A2,A3,A4,Coherent} |
| R8 | 刷新频率 | 日 |
| R9 | 小数位 | 1 位（默认待确认） |

| 业务含义 | ODS 列名（假设） | 用途 |
|----------|------------------|------|
| 变更类型 | `type` | 区分暂停/恢复单 |
| 项目名称 | `projectname` | 关联键 |
| 发布日期 | `releasedate` | R5 暂停/恢复时间 |

### 4.3 关键枚举值

**`hbmtpderivetype` 取值域**（应市类）：PA全部子型、PB全部子型、PC1、PC2
**`type` 取值域**：
- `HBMTProjectHoldRequest` = 项目暂停单
- `HBMTProjectResumeRequest` = 项目恢复单
- `HBMTProjectCancleRequest` = 项目取消单
- `HBMTProjectAdjustRequest` = 项目调整单

**`hbmtpproductline` 取值映射**：
- 终端：BOX, Multimedia
- 光模块：A1(TELECOM), A2(数通DATACOM), A3(FTTx), A4(无线), Coherent(相干)
- 不展示：A5(OSA), A7(芯片), A8(技术预研)

## 五、禁止行为

1. 禁止用 LIKE/模糊匹配替代 `HBMTPDERIVETYPE` 精确规则
2. 禁止用 `HBMTPPROJECTTYPE` 判定应市类
3. 禁止在目标值模拟表未闭环时落地 M2
4. 禁止遗漏暂停期剔除
5. 禁止把 A5/A7/A8 计入终端或光模块
6. 禁止跳过 MCP 表结构校验
