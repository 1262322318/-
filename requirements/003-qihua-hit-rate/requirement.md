## 业务背景
制作各营销部红黑榜，按项目维度监控央空内销（日立）产品的销售达标情况。根据上市时长将产品分为6个阶段，每个阶段有不同的达标判定逻辑。

## 核心概念

### 管理对象
- **项目**：一个项目对应多个销售型号（SKU）
- **项目信息来源**：`dim.dim_ipd_salemodel_dd` 的 `project_name`（项目名称）和 `project_code`（项目编码）
- **项目上市时间**：项目下所有销售型号中最早的上市时间
- **项目销量**：项目下所有SKU销量的汇总

### 上市月份计算
- 上市决策流程完成的下一个月为第1个月，上市当月为第0个月
- 公式：`(当前年 - 上市年) × 12 + (当前月 - 上市月)`
- 项目上市时间 = 项目下销售型号最早上市时间（`MIN(PG00025)`）

### 首年规划量
- 来源：销售型号基本信息表（`dim.dim_ipd_salemodel_dd`）的 `HX00020`（第一年规划量）字段
- 直接取值，无需汇总

### 累计连续12个月最大销量（滑动窗口）
- 从上市第1个月开始，取所有连续12个月窗口中销量之和的最大值
- 例：上市18个月，取第1-12月、第2-13月、...、第7-18月中最大的那个窗口

## 6个阶段的达标判定规则

### 阶段1：上市1-6个月 — 销售进度不达标
- **判定**：销量进度 < 时间进度 → 不达标
- **销量进度** = 累计销量 / 首年规划量
- **时间进度** = 上市月数 / 18

### 阶段2：上市7-18个月 — 销售进度不达标
- **判定**：销量进度 < 时间进度 → 不达标
- **销量进度** = 累计连续12个月最大销量 / 首年规划量
- **时间进度** = 上市月数 / 18

### 阶段3：上市19-23个月 — 企划未命中预警
- **判定**：累计连续12个月最大销量 < 首年规划量 → 未命中预警
- **完成率** = 累计连续12个月最大销量 / 首年规划量 < 100%

### 阶段4：上市24个月 — 企划命中率（核心指标）
- **①在产机型**：上市满24个月，连续12个月销量之和最大值 < 首年规划量 → 未命中
- **②停产机型（上市12-24个月）**：上市不足24个月但大于12个月的停产SKU，连续12个月销量之和最大值 < 首年规划量 → 未命中
- **③停产机型（上市6-12个月）**：上市不足12个月但大于6个月的当年退市SKU，累计销量 < 首年规划量 × 上市时长 / 12 → 未命中

### 阶段5：上市25-35个月 — 低销预警
- **判定**：累计连续12个月最大销量 < 低销门槛 → 低销预警
- **低销门槛**：固定值（暂定 100 台，后续调整）

### 阶段6：上市≥36个月 — 低销通报
- **判定**：累计连续12个月最大销量 < 低销门槛 → 低销通报
- **低销门槛**：同阶段5

## 涉及数据表

### 源表（读取）
- `dim.dim_ipd_salemodel_dd` — 销售型号基础信息（项目编码、项目名称、归属营销部、上市时间、首年规划量HX00020）
- `dim.dim_ipd_productmodel_dd` — 产品型号基础信息（内销/外销判断）
- `ods.ods_mr_v_app_fm_imat_saledata` — 管报实际销量
- `dw.dim_product_base_info_dd` — MDG主数据（物料→销售型号编码映射）

### 目标表（写入）
- `dws.dws_ipd_ipm_qihua_hit_detail_dd` — 企划命中率明细表（DWS层，待建）
- `ads.ads_ipd_ipm_qihua_hit_result_dd` — 企划命中率结果表（ADS层，待建）

## 数据流程
```
dim.dim_ipd_salemodel_dd (销售型号→项目映射、归属营销部、首年规划量HX00020)
  + dim.dim_ipd_productmodel_dd (内销/外销判断)
  + ods.ods_mr_v_app_fm_imat_saledata → dw.dim_product_base_info_dd (实际销量→按sale_model_code汇总)
         ↓
  按销售型号编码汇总实际销量，直接取首年规划量
         ↓
  按项目维度汇总（project_code聚合）
         ↓
  计算上市月份、滑动窗口12个月最大销量
         ↓
  按6个阶段判定达标/不达标
         ↓
dws.dws_ipd_ipm_qihua_hit_detail_dd (项目级明细)
         ↓
ads.ads_ipd_ipm_qihua_hit_result_dd (汇总结果)
```
