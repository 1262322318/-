## 每个需求文件夹包含
- `requirement.md` — 需求文档（业务背景、指标逻辑、专属业务规则、涉及表、验收标准）
- `tables.txt` — 涉及的表清单（源表+目标表）
- `lineage.md` — 血缘关系文档（数据流转图）
- `sql_scripts/` — 已开发的SQL脚本
- `permission_check.md` — 权限检查结果（可选）
- `changelog.md` — 变更记录（可选）

> **备注**：需求002、004~008为手工录入的历史脚本，其目标表DDL已在生产环境中创建完成，
> 因此这些需求的 `sql_scripts/` 中不包含 `create_tables.sql`。
> 仅新需求（如003及后续）需要在开发时生成建表DDL。

## 公共规则
跨需求复用的业务规则（产品线分类、日立口径、能效机转换等）统一维护在 `.kiro/steering/business_rules.md`，各需求通过编号引用。
