## 一、需求概述

将GP环境中的"中高端型号数占比"指标迁移到Doris环境。该指标按品牌×产品定位（端位）交叉维度，统计在销型号的型号数占比、销量占比、收入占比。

## 二、指标定义

| 字段 | 值 |
|------|-----|
| 指标名称 | 中高端型号数占比 |
| 计算公式 | 占比 = 某维度组合下的实际值 / 该品牌(或总体)下的总数 |
| 统计口径 | 产品型号口径 |
| 时间粒度 | 月度 |
| 覆盖产品线 | 冰箱、冷柜、洗衣机、家用空调、视像科技 + 汇总层 |
| 内外销 | 内销（明细）；全部（汇总层） |

## 三、zhibiao_type 清单

| zhibiao_type | 度量 | 计划值 |
|-------------|------|--------|
| 在销-品牌端位-型号数占比 | COUNT(DISTINCT model) | 有（odsmf_cm_tab28853） |
| 在销-品牌端位-销量占比 | SUM(sales_qty) | 无 |
| 在销-品牌端位-收入占比 | SUM(sales_amt) | 无 |

## 四、数据源

| 数据源 | 用途 | 月份 |
|--------|------|------|
| dws.dws_ipd_ipm_dxhxl_detail_dd | 型号/销量/销额明细 | 上月 |
| dws.dws_ipd_ipm_sale_model_detail_dd | 型号明细（无销量） | 当月 |
| ods.odsmf_cm_tab28853 | 计划值（型号数目标） | 全部 |

## 五、核心规则

### 维度交叉
- dimension_1（品牌）：各品牌独立 + "总体"汇总
- dimension_2（产品定位）：端位展开(低端/中端/高端) + 中高端合并
- 视像科技特殊：仅做中高端维度，不做端位展开

### 汇总层
- 智慧生活BG：冰箱/冷柜/洗衣机/视像科技(总体) + 家用空调(Hisense)
- 家电集团整体：冰箱/冷柜/洗衣机(总体) + 家用空调(Hisense)，不含视像科技

### 筛选条件
- dt_type = '月'
- in_out_sale = '内销'
- is_project = 'N'
- sales_type = '管报'（仅dxhxl表）
