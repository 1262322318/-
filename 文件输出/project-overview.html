1. 项目概述

本项目是一个AI驱动的ETL开发助手系统，专为海信集团IPD（集成产品开发）研发指标数据仓库建设而设计。系统通过Kiro Agent的Steering规则体系、Skills技能、Hooks自动化三层架构，实现了从需求分析、SQL脚本生成、代码审查、数据质量验证到文档自动化的全流程管理。

核心能力

智能需求分析

分叉链路v2.0对话流程：自动分类新建/变更需求，走不同处理路径。支持模式匹配加速分析，阶段门禁确保每步确认。

SQL脚本生成

基于12个实战模板和8条公共规则，自动生成符合Apache Doris 2.1+语法的ETL脚本，覆盖DWD/DWS/ADS各层。

SQL代码审查

6维度审查（规范/性能/业务/幂等/字段/可维护），100分制评分，支持自动修复建议。

知识管理

三层校验体系（实时校验→推理反馈→定期体检），支持多人投喂、日志追溯、过期检测。

数据质量管控

内置数据质量验证脚本，支持记录数验证、关键字段验证和业务规则验证。

文档自动化

自动生成需求文档、表清单、血缘关系、权限检查报告，Hook监控SQL变更自动更新。

业务目标

为海信集团各事业部（冰冷、洗护、空气、显示）提供7大核心研发指标的数据支撑：

指标业务含义考核目的
低效型号占比销量完成率<80%的型号占比监控产品效率，推动低效型号退出
新品规划命中率新品期内规划销量命中情况评估新品规划准确性
企划命中率央空日立按项目维度的销售达标率红黑榜考核各营销部
在销型号数当前市场在售的产品型号数量衡量产品组合丰富度
在产型号数当前正在生产的产品型号数量衡量生产复杂度
平台数平台库平台数 + 产品平台数衡量平台资产规模和利用率
单型号销量/单平台销量总销量/型号数（或平台数）衡量产品组合效率和平台投资回报

4. Steering 规则体系

5. Skills 技能体系

技能是预定义的执行步骤集合，通过触发词或 #技能名 手动引用激活。所有技能均为manual模式，不影响日常自由对话。

技能触发方式功能描述核心能力
etl-requirement #etl-requirement 或说"新需求/修改需求" ETL需求处理 分叉链路：新建链路A（A1~A7）+ 变更链路B（B1~B6），阶段门禁
knowledge-feeding #knowledge-feeding 或说"投喂知识" 知识投喂 4种投喂类型 + 智能校验引擎 + 推理反馈 + 日志记录
knowledge-health-check #knowledge-health-check 或说"健康检查" 知识库健康检查 5维度检查 + 健康评分 + 修复引导
sql-review #sql-review 或说"审查SQL" SQL代码审查 6维度审查（规范/性能/业务/幂等/字段/可维护），100分制
sql-template-extract #sql-template-extract 或说"提取模板" SQL模板提取 从已有SQL中自动识别可复用模式并写入模板库
project-audit 说"执行项目审计" 项目审计 生成交互式HTML审计报告，支持处理意见反馈
update-readmes #update-readmes 或说"更新README" README同步更新 扫描所有目录并同步更新README文件清单
