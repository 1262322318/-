## 阶段0：准备工作 ⭐⭐⭐⭐⭐

> 只在试用第一天做一次。**不投喂业务知识，Agent就是个通用工具**。

### 0.1 投喂业务知识 ⭐⭐⭐⭐⭐

**说**：「投喂知识」 或 `#knowledge-feeding`

Agent会问你：投喂什么类型？（表/规则/模式/批量）然后逐项采集，自动写入。

**第一天建议投喂**：
- 你负责产品线的特殊业务规则（3-5条）
- 团队内部约定但没文档化的口径（2-3条）
- 项目专属的表/字段（如有）

### 0.2 健康检查 ⭐⭐⭐⭐

**说**：「健康检查」

Agent从5维度体检知识库，给评分+修复建议。投喂完后跑一次确认没问题。

## 阶段1：日常使用 ⭐⭐⭐⭐⭐

### 1.1 新建需求 ⭐⭐⭐⭐⭐

**直接说**：
- 「新增一个XXX指标」
- 「我要做一个XXX占比统计」

**Agent会**：分类 → 澄清 → 表匹配 → 架构设计 → 汇总 → 生成SQL+文档。

**你的产出**：`requirements/{ID}/` 下完整的SQL和文档。

**预计耗时**：30分钟 ~ 2小时

### 1.2 变更需求 ⭐⭐⭐⭐⭐

**直接说**：
- 「004加个出点逻辑」
- 「低效阈值改成0.7」
- 「冰箱外销CKD有bug」

**Agent会**：定位资产 → 澄清变更 → 影响分析 → 精准修改 → 更新文档 → 提示下游。

**预计耗时**：10 ~ 30分钟

### 1.3 日常问答 ⭐⭐⭐⭐

**直接问**：
- 「PG00002是什么字段？」
- 「PUB-003的冰箱条件？」
- 「004和005依赖关系？」

**秒级响应**，不会触发流程。

### 阶段门禁规则 ⭐⭐⭐⭐⭐

新建/变更流程中，每步必须确认才前进：

| 你说 | 效果 |
|------|------|
| "确认/可以/继续/对的" | 前进 |
| "不对/调整/修改" | 留在当前步修正 |
| "回到上一步" | 回退 |
| "取消/不做了" | 退出流程 |

## 阶段2：质量保障 ⭐⭐⭐⭐

### 2.1 SQL审查 ⭐⭐⭐⭐

**说**：「审查SQL」 或 `#sql-review`

6维度评分（满分100）：编码规范 / 性能 / 业务合规 / 幂等 / 字段完整 / 可维护性。

**建议**：每个新生成的SQL都过一遍。

### 2.2 数据验证 ⭐⭐⭐

每个需求自动生成 `validate_data_quality.sql`，到Doris上手动跑验证。

> 当前Agent还不能直接连Doris执行，需要你切到Doris客户端跑。

## 阶段3：试用结束 ⭐⭐⭐⭐⭐

> 这是测试人员唯一需要主动做的"反馈"动作。

### 3.1 说一句话即可：「导出反馈」⭐⭐⭐⭐⭐

Agent会自动：
1. 扫描你电脑上所有的反馈记录和度量数据
2. 打包成单个markdown文件
3. 放到项目根目录：`feedback-export-{你的名字}-{日期}.md`
4. 提示你：「文件已生成，复制内容贴到钉钉/邮件，或把文件直接发给项目负责人」

### 3.2 反馈采集是怎么发生的？（你不需要做任何事，仅供了解）

| 时机 | Agent行为 | 你的负担 |
|------|-----------|---------|
| 每个需求结束后 | 自动问3个简短问题（10秒答完） | 答数字+短句即可，可全跳过 |
| 你随口吐槽时 | 后台静默记录 + 任务结束后追问1次 | 一句话补充即可，可跳过 |
| 你主动说"反馈/吐槽" | 引导式3问 | 简短回答即可 |

**你不需要**：写模板 / 改文件名 / 管目录 / 维护任何记录文件。

## 一段最简对话示例 ⭐⭐⭐⭐

```
你：004在销型号数加个出点逻辑

Agent：【分类判定】变更需求-字段新增（CHG-03），关联004。请确认？
你：对

Agent：【资产定位】找到 dws_xxx.sql，当前逻辑...请确认？
你：是

Agent：【变更澄清】1. 出点逻辑？2. 字段类型？3. 影响范围？
你：[回答]

Agent：【影响分析】修改dws第230行，下游005/007可能受影响。请确认？
你：确认

Agent：[修改+更新文档+度量+小调研]
```

## FAQ ⭐⭐⭐

### Q1：Agent生成的SQL有错怎么办？
说「审查一下这个SQL」让它自查。能识别就让它修，不能识别就直接吐槽：「这里有个bug，xxx不对」，Agent会自动记录。

### Q2：Agent对业务规则理解错了
当前对话直接告诉它正确规则；要永久生效说「投喂知识」。

### Q3：流程走到一半想重来？
说「回到上一步」/「重新来」/「取消」。

### Q4：能直接到Doris跑SQL吗？
**当前不行**。生成SQL后需手动到Doris执行。

### Q5：每次都要走完整流程吗？
不是。Agent会自动判断简短问答 vs 真需求。

### Q6：我电脑上的反馈数据怎么传给项目负责人？
说「导出反馈」，把生成的md文件发钉钉/邮件即可。**没有git/云**。
