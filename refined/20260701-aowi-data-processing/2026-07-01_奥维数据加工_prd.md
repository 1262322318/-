### 4.3 映射JOIN逻辑

映射表中空值字段代表"全匹配"。JOIN条件需按优先级匹配（精确匹配优先）：

```
匹配优先级：
1. prdct_line_name + prdct_cate + prdct_cate_dtl 三者都非空 → 精确匹配
2. prdct_line_name + prdct_cate 非空，prdct_cate_dtl 为空 → 按前两项匹配
3. prdct_line_name 非空，其余为空 → 仅按品线名称匹配
```

**SQL实现建议**：使用 LEFT JOIN + COALESCE，或优先匹配最精确记录。

## 五、计算字段逻辑

### 5.1 核心规格（core_spec）

整合原表 `spec_size`（产品尺寸）和 `match_size`（制冷匹数-空调）为统一字段。

**规则**：
- 当映射后 product_mid_class = '家用空调' 时：取 `match_size` 的值
- 其他产品中类：取 `spec_size` 的值

**业务含义按产品中类区分**：
| 产品中类 | 核心规格含义 | 单位 |
|----------|------------|------|
| 电视 | 尺寸 | 吋 |
| 家用冰箱 | 容积 | L |
| 家用冷柜 | 容积 | L |
| 洗衣机 | 容量 | Kg |
| 干衣机 | 容量 | Kg |
| 家用空调 | 匹数 | P |

**SQL实现**：
```sql
CASE 
  WHEN m.product_mid_class = '家用空调' THEN t.match_size
  ELSE t.spec_size
END AS core_spec
```

### 5.2 品牌系列（brand_series）

基于源表 `sub_brand_name` 字段做品牌归类：

```sql
CASE 
  WHEN sub_brand_name LIKE '%海信%' THEN '海信系列'
  WHEN sub_brand_name LIKE '%海尔%' THEN '海尔系列'
  WHEN sub_brand_name LIKE '%美的%' THEN '美的系列'
  WHEN sub_brand_name LIKE '%TCL%' THEN 'TCL系列'
  WHEN sub_brand_name LIKE '%小米%' THEN '小米系列'
  WHEN sub_brand_name LIKE '%创维%' THEN '创维系列'
  WHEN sub_brand_name LIKE '%容声%' THEN '海信系列'
  WHEN sub_brand_name LIKE '%科龙%' THEN '海信系列'
  WHEN sub_brand_name LIKE '%vidda%' THEN '海信系列'
  ELSE '其他'
END AS brand_series
```
