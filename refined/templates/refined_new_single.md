## 使用说明

1. refiner 从 converted 文档生成本模板时，通过 MCP 查询 table_metadata 填充字段名和备注
2. 确定度标记规则：
   - **确定**：需求文档中有精确值/枚举/公式，或 MCP 查表已验证
   - **待确认**：需求文档中模糊描述、"同XX"引用、或 MCP 未匹配到
3. 用户确认时重点关注：待确认项 + 差异清单
4. AI生成SQL时：确定项直接使用，待确认项按"AI默认假设"处理并在SQL注释中标注
