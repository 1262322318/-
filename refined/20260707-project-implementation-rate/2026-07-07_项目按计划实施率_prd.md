## 四、业务规则

### 4.1 项目情况判定（5种互斥状态，按优先级排序）

判定优先级：结题 > 延期 > 暂停 > 终止 > 正常

| 状态 | 判定规则 | 纳入合计分母 | 确定度 |
|------|----------|-------------|--------|
| 结题 | hbmtpproductionactualedate 落在统计当月 | ✅ 是 | 确定 |
| 延期 | 非结题，且开发或鉴定阶段存在延期（实际完成 > 计划完成+3工作日） | ✅ 是 | 确定 |
| 暂停 | projectcurrent = 'Hold' | ✅ 是 | 确定 |
| 终止 | projectcurrent = 'Cancel'，且取消单releasedate在当月，且当月无恢复单 | ❌ 否 | 确定 |
| 正常 | 不属于以上任何一种 | ✅ 是 | 确定 |

### 4.2 延期判定详细逻辑

延期 = 开发阶段延期 OR 鉴定阶段延期（任一即为延期）

| 阶段 | 计划时间字段 | 实际时间字段 | 延期条件 | 确定度 |
|------|-------------|-------------|----------|--------|
| 设计性试制（开发） | `hbmtpdesignestimatededate` | `hbmtpdesignactualedate` | 实际 > 计划+3工作日 | 确定 |
| 生产线试制（鉴定） | `hbmtpproductionestimatededate` | `hbmtpproductionactualedate` | 实际 > 计划+3工作日 | 确定 |

**"+3工作日"计算逻辑**（基于 `ods.odsrdm_holiday` 表）：

```
步骤1：查找计划完成时间在holiday表中对应的id
       - 如果计划完成时间本身是工作日 → 直接取对应id
       - 如果计划完成时间是非工作日（表中不存在） → 取最接近的下一个工作日的id
       SQL: SELECT MIN(id) FROM ods.odsrdm_holiday WHERE date_time >= {计划完成时间}
步骤2：id + 3 对应的date_time即为"计划+3工作日"
       SQL: SELECT date_time FROM ods.odsrdm_holiday WHERE id = {步骤1的id} + 3
步骤3：实际完成时间 > 步骤2的date_time → 判定为延期
```

**注意**：已判定为"结题"的项目不再参与延期判定

### 4.3 终止判定详细逻辑

1. projectcurrent = 'Cancel'
2. 在 `odsplm_bm_hbmtprojectadjust` 中存在 type = 'HBMTProjectCancleRequest' 的记录，且 releasedate 落在统计当月
3. 同一项目在当月内不存在 type = 'HBMTProjectResumeRequest' 的记录

关联方式：`odsplm_bm_hbmtprojectkpi.productname = odsplm_bm_hbmtprojectadjust.projectname`

### 4.4 计算规则

| 规则项 | 内容 | 确定度 |
|--------|------|--------|
| 合计 | 正常项目数 + 延期项目数 + 暂停项目数 + 结题项目数 | 确定 |
| 按计划实施率 | (正常项目数 + 结题项目数) / 合计 × 100% | 确定 |
| 暂停(累计) | 当前projectcurrent='Hold'的项目总数（纳入分母） | 确定 |
| 终止(当月) | 当月判定为终止的项目数（展示用，不进分母） | 确定 |

### 5.2 与参考对象的差异

| 差异点 | 011-project-dev-cycle做法 | 本需求做法 | 确定度 |
|--------|--------------------------|-----------|--------|
| 核心计算 | 计算开发周期天数(完成-立项-暂停) | 判定项目状态(结题/延期/暂停/终止/正常)并计数 | 确定 |
| 暂停处理 | 关联adjust表计算暂停时段天数 | 直接用projectcurrent='Hold'判定暂停状态 | 确定 |
| 延期判定 | 不涉及 | 需要引入工作日表(odsrdm_holiday)计算+3工作日 | 确定 |
| 终止判定 | 直接排除取消项目 | 需区分"当月取消且无恢复"为终止，并展示计数 | 确定 |
| 项目状态筛选 | 只取Complete/Review/Archive | 取Assign/Active/Create(未完成) + 当月完成(不限状态) | 确定 |
| 目标值 | 从飞书表读取目标值 | 不需要目标值 | 确定 |
| 输出指标 | 平均天数 | 百分比(实施率) | 确定 |

### 5.3 处理顺序与脚本清单

| 序号 | 层级 | 脚本名称(建议) | 功能 |
|------|------|---------------|------|
| 1 | DWS | dws_ipd_itd_project_impl_rate_dd.sql | 项目明细表（含状态判定：结题/延期/暂停/终止/正常） |
| 2 | ADS | ads_ipd_itd_project_impl_rate_result_dd.sql | 按事业部×产品线聚合的实施率 + 项目经理维度聚合 |

### 5.4 禁止行为

- 禁止对HBMTPDERIVETYPE使用精确匹配（必须用LIKE前缀匹配，如 LIKE 'PS%'）
- 禁止将终止项目纳入实施率分母（合计=正常+延期+暂停+结题，终止不进分母）
- 禁止跳过"结题优先"判定逻辑（当月鉴定完成的一律先判定为结题，不再参与延期判定）
- 禁止硬编码"+3天"为自然日（必须通过odsrdm_holiday表计算工作日）
- 禁止遗漏终止的"当月无恢复"校验（不能只看projectcurrent='Cancel'）
- 禁止将非终端/光模块产品线的项目纳入统计
