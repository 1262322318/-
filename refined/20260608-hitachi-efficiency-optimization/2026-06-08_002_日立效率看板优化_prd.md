## 十一、详细逻辑说明

### 11.1 is_project_nk 内控保护期逻辑

**核心思路**：is_project是集团逻辑（保持不变），is_project_nk是内控逻辑（在集团基础上放宽范围）。

**集团逻辑（is_project，新增品牌控制）**：
```sql
CASE 
  WHEN COALESCE(PC00025,'正常') = '1000-海信日立委外工厂' THEN 'Y' 
  WHEN COALESCE(HX00379,'否') = '是' THEN 'Y' 
  WHEN PC20080 NOT IN ('日立家装营销部','海信家装营销部','大客户部','工程营销部','电商事业部','约克家装营销部','海外业务部(氟系统)','科龙商空营销部') THEN 'Y'
  WHEN PG00020 = '外销' AND PG00069 NOT IN ('Hisense') THEN 'Y'
  ELSE 'N' 
END AS is_project
```

**内控逻辑（is_project_nk，新增）**：
```sql
CASE 
  WHEN COALESCE(PC00025,'正常') = '1000-海信日立委外工厂' THEN 'Y' 
  WHEN COALESCE(HX00379,'否') = '是' THEN 'Y' 
  WHEN PC20080 NOT IN ('日立家装营销部','海信家装营销部','大客户部','工程营销部','电商事业部','约克家装营销部','海外业务部(氟系统)','科龙商空营销部','海外业务部(大客户)','水机营销部','海外业务部(水系统)') THEN 'Y'
  WHEN PG00020 = '外销' AND PG00069 NOT IN ('Hisense','HITACHI','YORK') THEN 'Y'
  ELSE 'N' 
END AS is_project_nk
```

**关键差异**：
- 营销部列表：内控比集团多3个（`'海外业务部(大客户)','水机营销部','海外业务部(水系统)'`）
- 品牌控制：集团外销只认`'Hisense'`，内控外销认`'Hisense','HITACHI','YORK'`
- 品牌控制在CASE WHEN中显式判定（而非依赖WHERE过滤），确保集团和内控各自边界明确
- sale_model CTE的WHERE中外销品牌扩展为`('Hisense','HITACHI','YORK')`以保证内控所需数据能进入数据集

**sale_model CTE WHERE条件调整**：
- 现有：`and case when t2.PG00020 = '内销' then t1.PG00069 in ('Hisense','HITACHI','YORK','KELON') when t2.PG00020 = '外销' then t1.PG00069 in ('Hisense') else 1=2 end`
- 调整为：`and case when t2.PG00020 = '内销' then t1.PG00069 in ('Hisense','HITACHI','YORK','KELON') when t2.PG00020 = '外销' then t1.PG00069 in ('Hisense','HITACHI','YORK') else 1=2 end`
- 这样is_project_nk的逻辑就不会因为WHERE提前过滤而取不到数据
- is_project（集团逻辑）通过品牌判定逻辑在CASE WHEN中自行控制范围，不受影响
