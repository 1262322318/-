# XuebinLV IPM域闸门额外检查项（extra-checks.md）

> 追加到基线闸门之后，不替换基线检查项。

## G0 额外检查项（Phase 1 PRD）
- [ ] 是否明确了管理口径（产品型号口径 vs 销售型号编码口径）？
- [ ] 是否明确了覆盖产品线范围（内销哪些线+外销哪些线）？
- [ ] 是否有保护期/免统计期的定义？如有，月数是多少？
- [ ] 涉及规划量时，是否确认了BP vs LX的选择规则？
- [ ] 是否确认了排除条件（gorenje/ODM/模块组合/委外）？
- [ ] 是否明确了时间口径（当月/年累/近N月滚动）？

## G2 额外检查项（Phase 3 模型评审）
- [ ] DWS明细表是否包含is_project字段？判定逻辑是否清晰？
- [ ] 日立/央空产品线是否走了销售型号编码口径（PUB-004）？
- [ ] 视像科技是否处理了能效机转换（PUB-005）？
- [ ] 空调内外机转换规则是否正确应用（PUB-009补充）？
- [ ] 聚合规则中比率字段是否都保留了分子分母（防AVG反模式）？
- [ ] catalog.yaml中depends_on是否完整？新表是否已注册？
- [ ] 跨产品线统计时，product_line字段命名和值域是否与已有表一致？
