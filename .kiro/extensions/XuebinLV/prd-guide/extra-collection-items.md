# XuebinLV IPM域 PRD 额外采集项（extra-collection-items.md）

> Phase 1 采集时，IPM域特有的必采信息项清单。追加到基线采集项之后。

| 采集项 | 是否必采 | 说明 |
| --- | --- | --- |
| 管理口径 | 必采 | 产品型号口径/销售型号编码口径/物料口径，决定核心关联路径 |
| 覆盖产品线 | 必采 | 列出内销N条+外销N条产品线，未列出的视为不覆盖 |
| 保护期定义 | 视情况 | 涉及新品命中/低效判定时必采，其他指标可选 |
| BP/LX规则 | 视情况 | 涉及规划量对比时必采 |
| 排除条件 | 必采 | 确认gorenje/ODM/模块组合/委外等常见排除是否适用 |
| 时间口径 | 必采 | 当月/年累/近N月滚动/固定窗口 |
| is_project判定 | 必采 | 什么条件下标记为'Y'不纳入ADS统计 |
| 目标表复用or新建 | 必采 | 是否写入已有DWS/ADS表（需兼容性检查），还是新建 |
| 内外机转换 | 视情况 | 空调外销涉及整机/内机/外机时必采 |
| 能效机转换 | 视情况 | 涉及视像科技销量时必采 |
| 上游依赖 | 必采 | 是否依赖已有DWS表输出？需确认上游就绪度 |
