# 对话样本目录

本目录存放每次需求处理的对话简介，用于：
1. 多层复盘（用户级/需求级/框架级）
2. 未来功能完善的样本案例
3. 归因判定的人工校验材料

## 文件命名

`{需求ID}-{YYYYMMDD}.md`

## 内容结构

每个文件包含：
- 基本信息（日期、操作人、链路类型）
- 用户首次提交原文（完整版）
- 关键交互节点的对话片段
- 出现修正/否定信号的完整对话片段
- 最终汇总确认时的对话片段
- 1-3条关键发现总结

## 使用注意

- 不外发，仅用于内部复盘
- 涉及敏感业务术语时，可在Metrics JSON中设置 `"sanitized": true`，本目录文件保留摘要
