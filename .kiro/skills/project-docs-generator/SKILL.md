# 项目文档生成技能

## 触发词
用户说"生成项目文档"、"更新项目介绍"、"项目全景文档"时激活本技能。

## 执行步骤

1. 读取项目全部 steering 规则文件、skills 技能文件、hooks 配置、requirements 需求模块
2. 生成 **项目总览文档**（HTML格式），包含：项目概述、系统架构、文件结构、技术栈、评分维度、产品线矩阵等
3. 针对每个大功能模块，分别生成 **独立的详细介绍文档**（HTML格式），每个文档包含：
   - 模块概述与业务目标
   - 架构图 / 数据流转图
   - 核心设计决策与实现细节
   - 优缺点分析
   - 待改进项与建议
4. 所有产物存储在 `project-docs/` 目录下，每次触发**完全覆盖**（不留存历史版本）

## 产物目录结构

```
project-docs/
├── index.html                      # 项目总览（入口页，含5分钟上手、文件结构、模块导航、需求总览、产品线矩阵、系统边界）
├── module-pipeline.html            # 需求处理链路详解（分叉链路v2.0、分类判定、链路A/B详细步骤、典型场景走查）
├── module-steering.html            # Steering 规则体系详解
├── module-skills-hooks.html        # Skills 技能 + Hooks 自动化详解
├── module-requirements.html        # 需求管理体系详解（含依赖链、产品线矩阵）
├── module-data-warehouse.html      # 数据仓库架构详解（五层架构、表关系、数据流转）
├── module-sql-quality.html         # SQL质量管控详解（模板、规范、审查、幂等性）
├── module-change-management.html   # 变更管理与知识管理详解
└── module-automation.html          # 自动化与CI/CD详解（Hooks、调度、质量检查）
```

## 参考样式

参考 `文件输出/project-overview.html` 的视觉风格：
- 深蓝渐变 Header
- 白色卡片式 Section
- 代码块用深色背景
- 表格用浅蓝表头
- 响应式布局
- 各子页面顶部有返回 index.html 的导航链接

## 各模块文档必须包含的内容

### 通用结构（每个模块文档）
1. **模块概述**：一段话说明模块的定位和价值
2. **架构图**：用 ASCII/文本框图展示模块内部结构或与其他模块的关系
3. **核心设计**：关键设计决策、实现方式、配置说明
4. **数据流转图**（如适用）：数据从哪来、经过什么处理、到哪去
5. **优缺点分析**：当前方案的优势和已知局限
6. **待改进项**：明确的改进方向和建议优先级

### index.html 额外包含
- 5分钟上手指南（3种使用场景快速入门）
- 项目完整文件结构树
- 项目整体评价（当前成熟度、覆盖度）
- 各模块一句话摘要 + 跳转链接
- 项目统计数据（需求数、规则数、SQL脚本数等）
- 产品线覆盖矩阵
- 当前不支持/已知边界说明

## 执行规则

- 每次触发时**先清空** `project-docs/` 目录下所有文件，再重新生成
- 生成内容基于当前项目实际状态（读取真实文件），不使用缓存或历史数据
- HTML 文件纯静态，无需任何构建工具或后端
- 所有文档使用中文
