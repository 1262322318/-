| 需求来源 | 龚英 |

## 二、需求概述

### 背景

010需求的 `ads.ads_ipd_ipm_aowei_wd` 表是给产品规划智能体使用的数据，但由于数据量太大（全表大约一个亿数据），AI没办法直接使用。因此需要在此基础上扩增中间表的形式去实现AI的需求。

### 目标

在 `ads.ads_ipd_ipm_aowei_wd` 基础上，按多维度聚合生成若干中间表（行业市场分析），供产品规划智能体直接使用。

### 报表结构

共2大类、7个子报表，生成**7张独立的物理表**。分为两个模块，每个模块内如果有先后顺序，可以在数据加工时建立递进关系（如模块内上游表的结果作为下游表的输入）。

| 大类（模块） | 子表 | 内容 |
|------|------|------|
| 模块1：行业总体分析 | 表1-1 | 行业、分渠道数据 |
| 模块1：行业总体分析 | 表1-2 | 分渠道、分品牌数据 |
| 模块2：分价格段、分品牌市场分析 | 表2-1 | 各型号均价及价格段 |
| 模块2：分价格段、分品牌市场分析 | 表2-2 | 分价格段数据 |
| 模块2：分价格段、分品牌市场分析 | 表2-3 | 分价格段、分品牌数据 |
| 模块2：分价格段、分品牌市场分析 | 表2-4 | 分价格段、分规格段数据 |
| 模块2：分价格段、分品牌市场分析 | 表2-5 | 分价格段、分规格段、分品牌数据 |

**模块递进关系说明**：
- 模块2中，表2-1为型号级明细（含均价+价格段+规格段标记），可作为表2-2~2-5聚合的基础
- 模块1中，表1-1与表1-2粒度不同（1-1含"总体"虚拟维度，1-2按品牌展开），各自独立聚合或可共用中间结果

## 三、数据筛选规则（表1和表2通用）

### 3.1 数据维度筛选（隐含条件）

- 筛选"数据维度（周/月）"为**月**
- **重要**：这7张中间表只针对月维度的数据，不涉及周维度

### 3.2 时间范围

- 以当前年份往前推3年
- 例如当前为26年，则统计范围为：23年、24年、25年、26年T（26年1月至当月）
- 筛选"日期"为范围年份的日期范围（如202301-202312、202401-202412、202501-202512、202601-202606）

### 3.3 品牌筛选

**核心规则**：没有"统计品牌"维度的表（表1-1、表2-2、表2-4）展示的是**全市场**数据（不限品牌）。有"统计品牌"维度的表（表1-2、表2-1、表2-3、表2-5）只展示筛选品牌的数据行。

| 事业部 | 统计品牌维度值 |
|--------|----------|
| 空气 | 海信系列、海尔系列、美的系列、TCL系列、小米系列 |
| 冰冷 | 海信系列、海尔系列、美的系列、TCL系列、小米系列 |
| 洗护 | 海信系列、海尔系列、美的系列、TCL系列、小米系列、小天鹅（独立维度，通过"子品牌名称"='小天鹅'筛选，与系列并列） |
| 厨电 | 海信系列、海尔系列、美的系列、TCL系列、小米系列 |
| 显示 | 海信系列、TCL系列、小米系列、创维系列、三星（独立维度，通过"品牌名称"='三星'筛选，与系列并列） |

### 3.4 计算公式

| 指标 | 公式 |
|------|------|
| 总销量 | 单个型号的销量总和 |
| 总销额 | 单个型号的销额总和 |
| 产品均价 | 销额 ÷ 销量 |
| 额占有率 | 当前最小粒度维度的销额 ÷ 去掉最小粒度后整体的销额 |
| 量占有率 | 当前最小粒度维度的销量 ÷ 去掉最小粒度后整体的销量 |

### 3.5 占有率计算规则（重要）

**核心逻辑**：每张表的维度列表中，最后一个维度为"最小粒度"，占有率 = 当前最小粒度值的销额(量) ÷ 去掉该维度后的整体销额(量)。

**分母范围**：分母是**不限品牌的全市场数据**（奥维原表中该品类+该渠道的所有品牌总和），不是只算筛选出的几个品牌之和。

**没有"统计品牌"维度的表 = 全市场统计**（表1-1、表2-2、表2-4）。

**各表占有率分母对照**：

| 子表 | 最小粒度 | 占有率分母 |
|------|----------|-----------|
| 表1-1 | 统计渠道（线上/线下） | 同品类细分下全渠道（=总体）的全市场销额/销量 |
| 表1-2 | 统计品牌 | 同品类细分+同渠道下的**全市场**（不限品牌）销额/销量 |
| 表2-2 | 价格段 | 同品类细分+同渠道下**全价格段**的全市场销额/销量 |
| 表2-3 | 统计品牌 | 同品类细分+同渠道+同价格段下的**全市场**销额/销量 |
| 表2-4 | 规格段 | 同品类细分+同渠道+同价格段下**全规格段**的全市场销额/销量 |
| 表2-5 | 统计品牌 | 同品类细分+同渠道+同价格段+同规格段下的**全市场**销额/销量 |

**加工要点**：分子只取筛选品牌的数据行展示，但分母需要用不限品牌的全量数据计算。

### 3.6 价格段区间边界规则

- 区间为**左闭右开** `[最低均价, 最高均价)`
- 例：均价=6000 → 属于"6000-7000"段；均价=7000 → 属于"7000-8000"段
- 最高段（如"15000以上"，上限=99999999）视为左闭右闭

## 四、表1：行业总体分析

### 表1-1：行业、分渠道数据

**指标字段**：

- 总销量（全市场，不限品牌）
- 产品均价
- 额占有率（仅线上/线下有，总体无——因为总体=100%不需要）
- 量占有率（仅线上/线下有，总体无——因为总体=100%不需要）

**关于"总体"维度**：
- "总体"不是奥维原表中"线上线下"字段的某个值，而是一个**虚拟维度**
- 在数据加工时，需要将线上+线下的数据合计生成"总体"行
- 总体行只展示总销额/总销量/产品均价，不需要占有率（因为已是100%）

**时间列**：23年、24年、25年、26年T、25年同期（25年1月到与当前月对应的同期月份，如26年6月统计时取25年1~6月）

**示例**：
