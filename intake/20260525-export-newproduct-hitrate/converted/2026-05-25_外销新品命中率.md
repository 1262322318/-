# 外销新品命中率

## 一、基本信息

| 字段 | 值 |
|------|-----|
| 需求来源 | [待澄清] |
| 提出日期 | 2026-05-25 |
| 初步判断 | 新建 |
| 关联需求 | 无 |

## 二、指标定义

| 字段 | 值 |
|------|-----|
| 指标名称 | 外销新品命中率 |
| 业务含义 | 衡量外销新品上市后实际销量达成立项目标的情况 |
| 计算公式 | [待澄清] — 推测为：实际销量累计 / 立项目标累计，需确认命中率判定阈值 |
| 统计口径 | 产品型号 |
| 时间粒度 | 月度累计（上市后第1个月至当前月） |
| 覆盖产品线 | 显示、冰冷（冰箱+冷柜）、洗衣机、空调-家空、空调-轻商、厨电、激光 |
| 内外销 | 外销 |

## 三、业务规则

### 公共规则（7条产品线通用）

| 规则项 | 内容 |
|--------|------|
| 剔除OEM | 所有产品线均剔除OEM品牌 |

> 注：取值起点、取值终点、时间跨度等字段已在每条产品线中完整列出（对应原始Excel的BC列表头）。

### 产品线差异

#### 显示

**型号总数取值**

- **逻辑实体**：PLM：产品大类"显示类产品"，产品中类"电视"，产品小类"平板电视"，内销/外销取"外销"
  - 产品型号取字段"产品机型"
  - 销售渠道取字段"规划销售渠道"
  - 立项国家取字段"立项国家及地区"
  - 品牌取 Hisense + TOSHIBA + REGZA（剔除OEM）
- **管理维度**：产品型号
- **业务系统**：PLM，GSS
- **取值用属性/字段/表单**：PLM：实际上市时间、实际退市时间；再上市走信鸿3.0流程-产品退市重启流程
- **取值起点**：实际上市时间+4个月（上市为0月，至第4个月开始考核）
- **取值终点**：①新品期12个月；②新品期内决策退市的产品，取实际退市准备时间作为取值终点

**销量取值**

- **时间跨度**：上市后第1个月至当前月的累计立项目标及实际销量
- **立项目标销量**：取【规划销量】×50%为第一年目标；分月累计拆分：
  -1月0%、2月0%、3月0%、 4月16%、5月28%、6月38%、7月53%、8月60%、9月70%、10月74%、11月80%、12月100%
- **实际销量**：到型号的GSS系统协议发布订单量作为实际销量

#### 冰冷（冰箱+冷柜）

**型号总数取值**

- **逻辑实体**：HDRP：外销，大类"控温储藏类产品"
  - 冰箱：中类"家用冰箱"，剔除标机、样机、欧洲/蒙特雷/泰国工厂全散件

    4. OEM：品牌不取"OEM品牌"值
- **管理维度**：产品型号（剔除标机、样机、欧洲/蒙特雷/泰国工厂全散件）
- **业务系统**：HDRP，GSS
- **取值用属性/字段/表单**：HDRP：实际上市时间、实际退市准备时间；再上市目前OA流程-产品退市重启流程，后续切HDRP为再上市申请单时间
- **取值起点**：实际上市时间+4个月（上市月为0月，至第4个月开始考核）
- **取值终点**：①新品期12个月；②新品期内决策退市的产品，取实际退市准备时间作为取值终点

**销量取值**

- **时间跨度**：上市后第1个月至当前月的累计立项目标及实际销量
- **立项目标销量**：前6月40%均摊，后6月60%均摊
  - "产品类型"为配置型号：取【第一年配置规划销量】

- **实际销量**：到型号的GSS系统协议发布订单量
  - GSS"协议查询"→产品线选"冰箱"/"冷柜"，协议状态选"协议已发布"和"工艺BOM已发布"
