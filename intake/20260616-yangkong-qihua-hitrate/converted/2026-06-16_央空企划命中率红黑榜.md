| 需求来源 | 需求003企划命中率正式版逻辑 |

## 二、指标定义

| 字段 | 值 |
|------|-----|
| 指标名称 | 企划命中率（红黑榜） |
| 业务含义 | 制作各营销部红黑榜，以项目为管理对象，按上市月份分阶段判定销量达成情况 |
| 计算公式 | 见"三、业务规则"各阶段定义 |
| 统计口径 | 项目维度（项目下销售型号最早上市时间为该项目上市时间） |
| 时间粒度 | 月度 |
| 覆盖产品线 | 中央空调（内外销合计） |
| 内外销 | 内外销合计 |

## 三、业务规则

### 管理对象
- **管理维度**：项目（先做型号口径基础数据，再根据项目编码汇总成项目口径）
- **项目定义**：参考003需求，通过产品型号/销售型号上的项目编码字段关联
- **项目上市时间定义**：项目下销售型号最早上市时间为该项目的上市时间
- **上市月份定义**：从产品上市决策流程完成的下一个月为产品上市第1个月，上市当月定为0个月

### 取数逻辑

#### 内外销区分
- 筛选口径：产品型号的"内销/外销"字段
- 实际为中央空调内外销合计

#### 归属营销部
- 筛选字段：销售型号上的"营销部"字段
- 包含：日立家装营销部、海信家装营销部、大客户部、工程营销部、电商事业部、约克家装营销部、科龙商空营销部、海外业务部(氟系统)、海外业务部(大客户)

#### 标准品/定制产品规则
- **目标（首年规划量）**：取该项目下标准品的规划量
- **实际销量**：取项目下所有型号的销量（含定制）

#### 剔除条件
- 剔除规划生产基地：1000-海信日立委外工厂
- 剔除是否模块组合：是

#### 产品筛选
- **大类**：空调调节类产品
- **中类**：中央空调
- **小类**：单元式内机、单元式外机、多联机内机、多联机外机、空气源热泵两联供、空气源热泵三联供、新风换气机

### 阶段计算逻辑

#### 阶段1：上市1-6个月

- **取数起点**：实际上市时间不为空
- **取数终点**：实际停止生产时间为空
- **达成判定**：销量进度 < 时间进度 为未达成
- **销量进度**：累计销量 / 首年规划量
- **时间进度**：上市周期（月）/ 18

#### 阶段2：上市7-18个月

- **取数起点**：实际上市时间不为空
- **取数终点**：实际停止生产时间为空
- **达成判定**：销量进度 < 时间进度 为未达成
- **销量进度**：累计连续12个月最大销量 / 首年规划量
- **时间进度**：上市周期（月）/ 18

#### 阶段3：上市19-23个月

- **取数起点**：实际上市时间不为空
- **取数终点**：实际停止生产时间为空
- **达成判定**：累计连续12个月最大销量 < 首年规划量 为未达成
- **销量计算**：累计连续12个月最大销量 / 首年规划量 < 100%

#### 阶段4：上市24个月（企划命中率）

**①在产机型：**
- **取数起点**：实际上市时间不为空
- **取数终点**：实际停止生产时间为空
- **达成判定**：机型上市后24个月内连续12个月销量之和的最大值 < 首年规划量 为未达成
- **销量计算**：累计连续12个月最大销量 / 首年规划量 < 100%

**②当月停产机型（上市不足24个月但大于12个月）：**
- **取数起点**：实际上市时间不为空
- **取数终点**：实际停止生产时间不为空
- **条件**：在统计当月全部停产且上市时间不满24个月
- **达成判定**：机型上市后连续12个月销量之和的最大值 < 首年规划量 为未达成
- **销量计算**：累计连续12个月最大销量 / 首年规划量 < 100%

**③当月停产机型（上市不足12个月但大于6个月）：**
- **取数起点**：实际上市时间不为空
- **取数终点**：实际停止生产时间不为空
- **条件**：在统计当月全部停产且上市时间不满12个月
- **达成判定**：累计销量 < 企划中第一年目标销量 × 上市时长 / 12个月 为未达成

**说明**：当月停产机型，是指在考核当月，项目下所有的销售型号都有实际停止生产时间

#### 阶段5：上市25-35个月

- **管理维度**：产品为上市、退市准备状态的，仍以项目维度管理
- **取数起点**：实际上市时间不为空
- **取数终点**：实际停止下单时间为空
- **达成判定**：近12个月的连续销量 < 销量门槛 为未达成
- **说明**：门槛取数涉及PLM系统，PLM系统数据未校验，本次销量门槛取数为0，保留项目、型号、以及销量数据。不体现在红黑榜中

#### 阶段6：上市36个月以上

- **管理维度**：产品为上市、退市准备状态的，仍以项目维度管理
- **取数起点**：实际上市时间不为空
- **取数终点**：实际停止下单时间为空
- **达成判定**：近12个月的连续销量 < 销量门槛 为未达成
- **说明**：门槛取数涉及PLM系统，PLM系统数据未校验，本次销量门槛取数为0，保留项目、型号、以及销量数据。不体现在红黑榜中

#### 阶段7：上市25个月以上（停止下单状态）

- **管理维度**：产品为停止下单状态的，以销售型号维度管理，不再取项目，不显示在红黑榜中，有型号底表即可
- **取数条件**：实际停止下单时间不为空，实际停止生产时间为空
- **达成判定**：近12个月的连续销量 < 销量门槛 为未达成
- **说明**：门槛取数涉及PLM系统，PLM系统数据未校验，本次销量门槛取数为0，保留项目、型号、以及销量数据。不体现在红黑榜中
